## Publishing rules

1. **Publish on your own domain first** if you can. It gives you the canonical
   URL, keeps the SEO value and lets you add FAQ schema. If you only publish on
   Medium, use the Medium URL as canonical.
2. **Set the canonical URL** in Medium's story settings when cross-posting. This
   avoids duplicate-content competition.
3. **Keep the title and first 100 words keyword-focused** but do not stuff.
4. **Use one H1 only.** The article files already have one.
5. **Add the links as written.** They point to the docs, readiness index,
   adoption index and GitHub.
6. **Add a cover image** and set the alt text from the table above.
7. **Disclose affiliation** in the byline or first paragraph: "I built
   grapheway." Readers and platforms reward honesty.
8. **Do not buy views, stars or downloads.** It violates platform rules and
   destroys trust.
